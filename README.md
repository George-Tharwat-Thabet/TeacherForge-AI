# 🎓 TeacherForge AI

**AI-powered teaching assistant that transforms how educators create, grade, and communicate.**

## 🎯 The Problem

Teachers spend **50%+ of their time** on administrative tasks instead of teaching:
- Creating lesson plans from scratch takes hours
- Generating varied exam questions is tedious and repetitive
- Grading 100+ papers manually is exhausting and time-consuming
- Writing personalized parent communications feels overwhelming
- Managing timetables and schedules is a constant juggle

**Result:** Teacher burnout, less time for actual teaching, and students who miss out on personalized attention.

- **K-12 Teachers** who want to reclaim their time

- **Tutors & Educators** who need quick, quality content
- **Educational Institutions** aiming to modernize their workflow

## ✨ The Solution

TeacherForge AI leverages Google's Gemini AI to automate the heavy lifting:

### 📚 Lesson Generator
Upload textbook pages (images/PDFs) and get complete lessons in seconds:
- Detailed explanations
- Ready-to-use presentation slides
- Quiz questions with answers
- Homework assignments
- Export to PDF (color or print-friendly B&W)

### 📝 Exam Generator
Create 5 different exam types in under 10 seconds:
- Multiple Choice
- Essay Questions
- Matching
- True/False
- Fill in the Blank

Supports both manual topic entry and lesson file uploads.

### ✅ Auto-Grading
Grade 100+ papers with personalized feedback in under 2 minutes:
- Upload answer sheets (images/PDFs)
- AI analyzes and scores responses
- Generates constructive, personalized feedback
- Detailed breakdown per question

### 📊 Analytics Dashboard
Track student performance and identify trends at a glance.

### 📅 Timetable Manager
Organize and manage class schedules efficiently.

### 💌 Parent Letters
Generate professional parent communications quickly.

### 🔄 Lesson Remix
Transform existing lessons into new formats and styles.

## 📦 Getting Started

### Prerequisites
- Node.js 18+
- Google Gemini API key

### Installation

```bash
# Clone the repository
git clone https://github.com/George-Tharwat-Thabet/TeacherForge-AI.git

# Navigate to project
cd teacherforge-ai

# Install dependencies
npm install

# Create environment file
cp .env.example .env

# Add your Gemini API key to .env
VITE_GEMINI_API_KEY=your_api_key_here

# Start development server
npm run dev
```

### Build for Production

```bash
npm run build
npm run preview
```
